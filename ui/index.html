Classifier = best road per GPS point, one point at a time. + HMM = the same probabilities joined into one connected route. Precision, recall and F1 are weighted by road length and ignore the order of roads, so they are optimistic; continuity and discontinuities show whether the path is really connected.

The accuracy numbers are computed by the server. This page never receives the reference route.
